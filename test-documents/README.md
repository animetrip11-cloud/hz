# Только тестовые документы

Эти документы не включаются в приложение и не появляются в пользовательской библиотеке автоматически.

`python3 tools/generate_fixtures.py` воспроизводит PDF с тремя нумерованными страницами и CBZ с разными пропорциями картинок. CBZ содержит `1.png`, `2.png`, `10.png`, `chapter 2/1.png`; служебный `__MACOSX/._1.png` и текст игнорируются. Есть пустой и повреждённый архивы.

Для проверки дублей скопируйте корректный CBZ под другим именем. Для проверки одинакового имени/разного содержимого переименуйте другой валидный файл. Исходные файлы при импорте остаются без изменений.

`Long-strip.cbz`: PNG 600 × 24000 с тремя цветными полосами и горизонтальными маркерами. Проверяет региональное декодирование, ширину отображения и восстановление прокрутки. Данные создаются тем же генератором; тест ZIP64 со смещением за 4 ГиБ использует временный разреженный файл и удаляет его после проверки.

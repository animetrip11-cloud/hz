# Подготовка к RuStore

Release: `dev.koma.reader`, версия `1.0.0`, versionCode `4`, Android 8.0+,
targetSdk 35. Режим отладки отключён; debug-инструменты Compose в release не входят.

```sh
./gradlew :app:assembleRelease :app:lintRelease
bash tools/sign_release.sh
```

Для подписи задайте `ANDROID_HOME`, `KOMA_KEYSTORE` (путь вне репозитория),
`KOMA_KEY_ALIAS`, `KOMA_STORE_PASSWORD`, `KOMA_KEY_PASSWORD` в своём окружении.
Скрипт выравнивает APK, подписывает и проверяет подпись. Готовый файл:
`downloads/KOMA-release.apk`. Неподписанный APK для магазина не подходит.

Ключ публикации и пароли нельзя коммитить или выкладывать рядом с APK.
Храните резервную копию ключа и паролей отдельно: обновления должны иметь
ту же подпись и больший versionCode. Отображаемая версия остаётся 1.0.0.

При отличии release-подписи от установленной debug-подписи обновление поверх
не установится. Сначала экспортируйте резервную копию JSON в настройках KOMA,
сохраните её вне приложения, затем переустановите и восстановите копию.
Исходные PDF/CBZ потребуется выбрать снова для выдачи разрешений Android.

В RuStore создайте карточку приложения, приложите подписанный APK, описание,
иконку и снимки интерфейса; заполните сведения о данных и контакты разработчика.
APK проходит модерацию магазина, результат модерации сборка сама не гарантирует.

## Резервная копия подписи

Ключ и AES-256 зашифрованная резервная копия находятся вне репозитория,
в защищённом каталоге рабочей среды. Архив и пароль ещё не переданы владельцу.
Перед публикацией в магазине необходимо завершить передачу и сохранить
архив и пароль в надёжном месте. Без ключа невозможно подписывать обновления.
Внутри архива `koma-release.jks`, alias `koma-release` и `signing.properties`.
Незашифрованные ключ и пароли нельзя публиковать.

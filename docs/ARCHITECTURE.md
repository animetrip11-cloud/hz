# Архитектура

Один app-модуль: `core` (модель и правила), `data` (Room, DataStore, импорт, резервная копия), `reader` (источники PDF/ZIP), `ui` (Compose/Navigation/ViewModel).

Документы копируются через ContentResolver потоками по 64 КиБ в `filesDir/staging`. В этой же операции считается SHA-256, проверяется свободное место и отмена. После проверки содержимого пользователь видит подтверждение. Финализация переименовывает staging-файл в `filesDir/manga/<sha256>` и записывает метаданные транзакцией. Манга не хранится в cacheDir. При отмене/новом запуске staging очищается. При первом обращении к библиотеке проверяется наличие файлов и удаляются бесхозные копии, оставшиеся при сбое между rename и транзакцией. После успешной финализации отдельный том остаётся в базе даже при отмене следующих файлов. Импорт принадлежит ViewModel: при сворачивании продолжает работу, завершение процесса отменяет незавершённые файлы; это не гарантированная фоновая загрузка/foreground service.

PDF открывается с read-only ParcelFileDescriptor; открытая страница всегда закрывается до закрытия PdfRenderer. ZIP индексируется без распаковки на диск; записи читаются выборочно. Порядок — естественный для полного пути с регистронезависимым сравнением токенов; при равенстве используется исходный полный путь (регистрозависимо). Это даёт стабильный порядок для A/a и 01/1. Служебные/скрытые пути, `..`, каталоги и неизвестные расширения не являются страницами.

Рендер/копирование/хеширование/резервные копии исполняются на Dispatchers.IO. Размер страницы ограничен 4 млн пикселей, миниатюры — 0,5 млн; JPEG/PNG/WebP декодируются с inSampleSize. При масштабе >1,5 запрашивается большее разрешение, максимум 2400 px по ширине. Оперативный LRU страниц ограничен 16 МиБ, подгружается одна соседняя страница; вытеснение не recycle-ит битмапы, ещё используемые интерфейсом. Кэш миниатюр ограничен 32 МиБ и пересоздаваем. Интерфейс не инвертирует и не зеркалит мангу.

Позиции, закладки и история — разные таблицы. Общие предпочтения — DataStore; индивидуальные параметры — nullable Overrides, где null означает наследование. Перемотка держит preview отдельно от сохранённой страницы. Яркость/keep-screen-on/клавиши громкости действуют только пока читалка находится в композиции.

Приложение не запрашивает INTERNET, MANAGE_EXTERNAL_STORAGE или общие разрешения на файлы. Нет аккаунта, сети или сервисных ключей. Android auto-backup выключен: ручной экспорт явно объясняет границы копии.

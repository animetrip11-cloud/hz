# Архитектура KOMA 1.1

Один app-модуль: core (модель и правила), data (Room/DataStore/импорт/backup), reader (PDF/ZIP и декодирование), ui (Compose/Navigation/ViewModel).

## Хранение исходников

После OpenMultipleDocuments берётся persistable READ URI permission. ContentResolver читает документ потоками по 64 КиБ для SHA-256 и определения формата. Новый файл не записывается ни в filesDir, ни в cacheDir. PdfRenderer получает seekable ParcelFileDescriptor. CBZ получает FileChannel через AutoCloseInputStream; SeekableZip читает только центральный каталог и выбранные записи, поддерживает ZIP64/длинные смещения, UTF-8/Unicode path extra, stored/deflate. Распаковки архива на диск нет. Неподдерживаемый или временный поставщик не вызывает молчаливого копирования: приложение сообщает о необходимости выбрать подходящий локальный документ.

URI привязан к Volume.sourceUri. Идентичность тома — SHA-256 исходных байтов, поэтому переименование/повторный выбор не меняют позиции и закладки. При изменении исходника пользователем байты уже не считаются тем же документом. Для офлайн-доступа исходный файл должен находиться локально и оставаться доступным.

В Room 2 добавлена nullable sourceUri с явной Migration(1,2). NULL означает приватную копию старой версии либо восстановленную запись без файла. Старые данные/копии при обновлении остаются на месте. При повторном выборе совпадающих байтов сначала проверяется исходник, затем транзакционно записывается URI в существующий том; только после этого удаляется старая приватная копия. При ошибке до транзакции копия сохраняется. Исходник ContentResolver не изменяется и не удаляется. Незавершённые staging-файлы старой версии очищаются при запуске.

## Длинные страницы

PageSource предоставляет число страниц, исходные dimensions, обычный render и renderTile. Для CBZ высотой больше трёх ширин по умолчанию выбирается прокрутка на ширину экрана. Внутри страницы используются участки высотой около 1,5 исходных ширин; BitmapRegionDecoder декодирует только нужный Rect. Поток записи остаётся открытым до окончания decodeRegion, затем decoder и поток освобождаются.

Одна ограниченная LazyColumn содержит видимые участки, а в вертикальном режиме — страницы и их участки. Metadata подгружается для видимых страниц; неизвестная страница не декодируется в гигантский временный bitmap. Высота элементов считается по исходным пропорциям, не по уменьшенной миниатюре. Позиция хранится как индекс страницы и нормализованная координата по полной высоте исходной страницы. При восстановлении она преобразуется в участок и смещение внутри него; сохранение выключено до окончания восстановления, чтобы начальная загрузка не затирала позицию нулём.

PDF не переводится в CBZ-тайлы: его прежний PdfRenderer-путь сохраняется. Автоматика длинных страниц включается только для CBZ и может быть отключена в общих/индивидуальных настройках.

Обработка файлов, SHA-256, архивов и рендер исполняются на IO. Семафор ограничивает декодирование участков двумя одновременными заданиями; ожидающие загрузки отменяются при уходе элементов. Обычный bitmap ограничен 4 млн пикселей, миниатюра — 0,5 млн, видимый участок — 4 млн. LRU обычных страниц — 16 МиБ, дисковый кэш миниатюр — около 32 МиБ. Масштабирование не зеркалит и не инвертирует рисунок.

## Состояние

Позиции, закладки и история разделены. Общие настройки — DataStore, индивидуальные — nullable Overrides в Room. Перемотка держит preview отдельно до фактического перехода. Яркость/keep-screen-on/громкость восстанавливают системное поведение при уходе из читалки.

Backup schemaVersion 1 сохраняется совместимым: добавленные настройки имеют значения по умолчанию, device-local sourceUri не экспортируется и игнорируется при восстановлении. Книги выбираются снова и связываются по содержимому. Разрушительных миграций нет. Приложение не имеет INTERNET/MANAGE_EXTERNAL_STORAGE и не нуждается в сервере или ключах.

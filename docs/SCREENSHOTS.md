# Снимки реализованного интерфейса

Это **рендеры работающего Compose-кода в Robolectric**, Android API 28, native graphics, окно 411 × 891 dp (масштаб 2). Они получены автоматическим тестом через Canvas реального decorView. Это не исходные макеты и не скриншоты успешно пройденного теста на физическом устройстве.

В заполненных экранах использован собственный CBZ с пронумерованными страницами из test-documents/. Он не включается в приложение как предустановленная библиотека.

Сверены иерархия библиотеки, графитовая палитра, отсутствие старого K., видимость основного действия пустой библиотеки, скрытие глобальных вкладок на вложенных экранах, отсутствие растяжения страниц и выделение активных элементов. Исходные изображения из references/ использовались как ориентиры, не как экраны приложения. Системный фиолетовый цвет выбранных фильтров заменён фирменным сочетанием Elevated/Accent после первой визуальной проверки.

Снимок `screenshots/environment/android26-system-ui-anr.png` — **ошибка System UI тестовой среды**, а не экран KOMA. Он сохранён как свидетельство ограничения программной эмуляции без /dev/kvm.

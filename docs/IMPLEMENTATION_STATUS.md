# Статус реализации KOMA 1.1

Debug APK собран, 21 автоматическая проверка прошли, lint: 0 ошибок. Полный прогон на устройстве не подтверждён из-за нестабильной программной эмуляции без KVM. Подробные результаты: VERIFICATION.md.

## Реализовано в исходниках

- Нативный Android / Kotlin / Compose, одна Activity, Navigation Compose, Room, DataStore.
- Палитра KOMA, пустая первая библиотека, знак КАДР в SVG/VectorDrawable, adaptive/monochrome и splash.
- Библиотека с поиском, фильтрами статуса/формата, сортировкой и переключением сетка/список.
- Произведения, редактирование названий, порядок и перенос томов, отдельный статус.
- Выбор нескольких документов через SAF и входящие VIEW/SEND, постоянные ссылки доступа к исходникам без полной копии.
- Потоковая проверка SHA-256 без записи копии, проверка формата/доступа, дубли и подтверждение группировки.
- PDF через PdfRenderer; CBZ с PNG/JPEG/WebP и естественным порядком путей.
- Читалка RTL/LTR/лента, масштабирование/панорамирование, миниатюры и предпросмотр перемотки.
- Позиции, относительное положение ленты, индивидуальные nullable-переопределения настроек.
- Закладки с заметками/поиском/фильтром, отмена удаления, отдельная история по дням.
- Реальный размер копий и кэша, безопасная очистка кэша, подтверждение удаления тома.
- Версионированная JSON-копия без книг, проверка целостности и слияние с приоритетом локальных данных.
- Генератор тестовых документов, unit/Room-тесты и инструментальная проверка навигации.

## Реализовано, но требует проверки на устройстве

PDF/PdfRenderer на настоящем Android; разные SAF-провайдеры и системные окна экспорта/восстановления; все комбинации переноса/порядка томов; реальная нехватка места; большие и защищённые документы; мультитач/лента/яркость/клавиши; завершение процесса; увеличенный системный шрифт и launcher Android 13+. Activity recreation не заменяет тест завершения процесса. Таблица сценариев: VERIFICATION.md.

## Не входит в первую версию / не реализовано

Развороты, обрезка полей, подключение папки, экспорт книг вместе с копией, универсальный ввод пароля PDF, Windows. Нет гарантированной фоновой службы импорта, тайлового неограниченного зума или замены локальных данных при восстановлении: восстановление всегда объединяет с приоритетом локальных значений. См. ROADMAP.md.

## Изменения по отзыву пользователя

Длинные CBZ автоматически переходят к прокрутке по ширине с региональным декодированием, одновременно работают не более двух заданий декодирования участков. Прокрутка восстанавливается до точного видимого участка. Предложение завершить длинный том появляется в конце ленты. PDF не переведён в CBZ-тайлы.

Новые файлы не копируются в приложение. Источники открываются с persistable READ permission через дескриптор. Room 1 → 2 сохраняет старые записи; прежние приватные копии удаляются после подтверждённого повторного выбора совпадающего исходника. Резервные копии остаются совместимыми, локальные URI в них не переносятся. Для офлайн-доступа оригинал должен оставаться локально доступным.

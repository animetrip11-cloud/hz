# Резервная копия KOMA, schemaVersion 1

JSON UTF-8 (не более 16 МиБ при восстановлении). Корневые поля:

- `schemaVersion`: 1;
- `works`: ID, название, статус, время добавления, nullable JSON индивидуальных переопределений;
- `volumes`: SHA-256 оригинальных байтов (`hash`), ID произведения, имя файла и название тома, формат, размер, число страниц, ручной порядок, индекс страницы с 0, относительное смещение 0…1, признак завершения;
- `bookmarks`: уникальная пара SHA-256 + индекс страницы, заметка и время;
- `preferences`: общие параметры чтения и вид библиотеки.

Копия **не содержит PDF/CBZ**. История — отдельный журнал, не включается в экспорт. Поле `available` при восстановлении не считается доказательством наличия файла: проверяется локальная копия с соответствующим хешем.

Перед записью проверяется весь документ: версия, уникальность ID/хешей, связи, формат хеша, границы страниц, допустимые настройки. Изменения таблиц применяются одной транзакцией Room. Неизвестные JSON-поля допускаются для совместимости, неизвестная версия отклоняется.

Слияние: локальное произведение с тем же ID и локальный том с тем же SHA-256 целиком имеют приоритет. Новые записи добавляются; существующая пара том/страница закладки сохраняет локальную заметку. Общие настройки восстанавливаются только в пустую библиотеку. Замены существующих данных интерфейс не предлагает: операция всегда объединяет. Это исключает молчаливое затирание текущей работы.

Отсутствующие PDF/CBZ представлены записями «Добавьте файл». Повторный импорт идентичных байтов привязывает файл к записи, сохраняя название, порядок, позицию и закладки. Исходное имя и URI не являются идентификатором.

Схема Room версии 1 находится в `app/schemas/`. Разрушительное восстановление базы (`fallbackToDestructiveMigration`) не используется. При повышении версии нужна явная Migration и тест.

# Проверка KOMA 1.1.0

29 октября 2026. Android minSdk 26 / targetSdk 35, Gradle Wrapper 8.11.1, AGP 8.9.2, Kotlin 2.1.20, JDK 21.0.8+9. Robolectric обновлён до стабильного 4.17: прежний 4.14.1 подменял BitmapRegionDecoder пустым bitmap; assertions пикселей не отключались.

## Выполнено для обновления

```sh
./gradlew --no-daemon :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest
```

- APK 1.1.0 / versionCode 2 успешно собран. Поставляемая копия: downloads/KOMA-debug.apk, SHA-256 рядом.
- Подпись APK проверена apksigner; SHA-256 сертификата совпадает с опубликованным APK 1.0.0. Application ID dev.koma.reader сохранён. Можно обновлять приложение с сохранением базы, без удаления.
- 21 автоматический тест: 0 failed/errors/skipped. XML и журнал итоговой сборки — в docs/verification/.
- Lint: 0 ошибок; оставшиеся предупреждения записаны в verification/lint-results-debug.txt.
- assembleDebugAndroidTest успешно собирает Android-тест. Физическое устройство в этой среде недоступно; его сборка не считается успешным аппаратным прогоном.

## Проверки, относящиеся к жалобе пользователя

- **LongPageTest:** реальный PNG 600 × 24000 в CBZ; размеры/27 участков; проверка пикселей красного, зелёного и синего участков настоящим native BitmapRegionDecoder, а не тестовой заглушкой. Ширина региона не уменьшается из-за высоты всей страницы; bitmap в пределах 4 млн пикселей.
- **AndroidUiTest:** библиотека → импорт → CBZ → перелистывание → закладка → Activity recreation; затем импорт длинного CBZ. Проверяется, что видимый участок занимает не менее 95% ширины окна, прокрутка сохраняет offset > 0, после recreation восстанавливаются тот же видимый участок и его координата (погрешность менее 4 px). Сняты рендеры до/после восстановления.
- **SafSourceTest:** ContentProvider с content:// URI, сохранение READ permission, чтение ZIP через ParcelFileDescriptor/FileChannel, отсутствие приватной копии, удаление записи без удаления исходника. Это реальный путь ContentResolver в Robolectric, а не только file:// тест.
- **RepositoryTest:** импорт не создаёт filesDir/staging-копию; повторное открытие Repository продолжает читать оригинал; проверенный переход со старой копии сохраняет hash, workId, название, порядок, completed, page/offset, заметку и overrides; неудачный переход не удаляет копию; недоступный исходник не стирает позиции/закладки; backup не экспортирует URI устройства. Существующие тесты дублей, отмены, слияния и удаления также выполнены.
- **MigrationTest:** создаётся настоящая база схемы Room 1 с библиотекой, историей, страницей 6 и заметкой; открывается Room 2 с MIGRATION_1_2. Данные сохранены, sourceUri NULL для старых копий, разрушительного пересоздания нет.
- **SeekableZipTest:** stored/deflate, Unicode, служебные записи, natural sort и чтение выбранных записей; отдельный ZIP64 с local header за границей 4 ГиБ проверяет Long offsets. Разреженный тестовый файл удаляется после теста.
- CoreTest (5), IconTest (1) и проверки существующего чтения продолжают проходить. Всего: Core 5 + Repository 9 + UI 1 + Icon 1 + Long 1 + Migration 1 + SAF 1 + ZIP 2 = 21.

Скриншоты — [SCREENSHOTS.md](SCREENSHOTS.md). Получены из реального Compose-кода в Robolectric native graphics, не из презентационных макетов. Пользовательский PDF подтверждён самим пользователем на телефоне; пользовательский CBZ не был приложен. Его масштабирование воспроизведено на собственном длинном CBZ. Это не утверждение о проверке конкретного архива пользователя.

## Ограничение аппаратной проверки

В текущей машине нет /dev/kvm. Предыдущие попытки на Android 30 x86_64 и Android 26 x86 в программном режиме сопровождались service not found, таймаутами и System UI isn’t responding. Runner начинал connectedDebugAndroidTest, но за 180 секунд сценарий не завершился (exit 124). Не выдаётся за пройденный тест или дефект KOMA. Исторический журнал — verification/device-attempt.log, свидетельство System UI — screenshots/environment/. Нового успешного аппаратного прогона 1.1 не заявляется.

# Фактическая проверка KOMA

Дата: 29 октября 2026. Репозиторий: `/workspace/hz`.

## Успешные команды

Выполнены через поставляемый Gradle Wrapper 8.11.1, JDK Temurin 21.0.8+9 и официальный Android SDK 35 / Build Tools 35.0.0:

```sh
./gradlew --no-daemon :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest
```

В облачной среде использованы ANDROID_HOME и JAVA_HOME, системное хранилище CA и параметры существующего HTTP-прокси. Ни TLS, ни проверка контрольных сумм не отключались. `local.properties` удалён перед проверкой Wrapper; абсолютный SDK-путь не включён в отслеживаемые настройки проекта.

- Debug APK успешно собран. Поставляемая копия: `downloads/KOMA-debug.apk`, SHA-256 — в соседнем файле.
- APK Signature Scheme v2 проверен `apksigner verify --verbose`.
- `aapt dump badging` подтвердил dev.koma.reader, versionName 1.0.0, minSdk 26, targetSdk 35. INTERNET и общий доступ к накопителю отсутствуют.
- Gradle Wrapper успешно загрузил и проверил свой дистрибутив.
- Unit/Robolectric: **13 тестов, 0 failed, 0 errors, 0 skipped**.
- Android-инструментальный APK успешно собран. Его выполнение не приравнивается к сборке.
- Lint: **0 ошибок**; предупреждения сохранены в `verification/lint-results-debug.txt`.
- `git diff --check` выполнен.

JUnit XML и итоговый журнал находятся в `docs/verification/`.

## Что проверяют 13 тестов

- CoreTest (5): естественная сортировка полных путей, стабильность регистра/ведущих нулей и больших чисел, исключение служебных записей, кириллическая группировка, наследование настроек, JSON round-trip и валидация резервной копии.
- RepositoryTest (6): позиции после повторного открытия Room; уникальность закладки и изменение заметки; независимость очистки истории; слияние резервной копии и сохранность базы при ошибках; повторное связывание отсутствующего файла по SHA-256; одинаковые байты с разными именами; одинаковые имена с разным содержимым; отмена копирования и сохранность оригинала; точечное удаление тома и связанных записей.
- AndroidUiTest (1 последовательный сценарий): пустая библиотека и четыре вкладки → настоящий CBZ через экран подтверждения → произведение → рендер страницы → свайп RTL → закладка → ActivityScenario.recreate → сохранённая страница → библиотека, закладки и история. Все утверждения выполнены; картинки страниц декодируются, данные не подставляются вручную.
- IconTest (1): цветной и монохромный foreground при 24/48/96 px сохраняют ровно три раздельных компонента, существенные пиксели находятся в круглой центральной safe area. Круговая безопасная область также помещается в обычную скруглённую маску.

Robolectric проверяет реальные Android/Compose-компоненты в JVM. Это не доказательство поведения всех аппаратных декодеров, document providers и системных жестов на телефоне. Скриншоты и их происхождение: [SCREENSHOTS.md](SCREENSHOTS.md).

## Попытка проверки на эмуляторе

В машине отсутствует `/dev/kvm`. Установлены официальные Emulator 37.2.12 и образы Android 30 x86_64 / Android 26 x86. Запускались только наши отдельные AVD, в программном режиме.

Android 30 загружался около 10 минут, затем терял package/activity services; установка возвращала Broken pipe / service not found. Android 26 загрузился, APK фактически появился в `pm path`, но запуск завершался таймаутом и системным окном **System UI isn’t responding**. Это окно сохранено отдельно от снимков приложения.

Выполнена попытка:

```sh
./gradlew --no-daemon :app:connectedDebugAndroidTest
```

Runner сообщил `Starting 1 tests on koma26(AVD) - 8.0.0`, но сценарий не завершился за 180 секунд. Команда остановлена по таймауту (exit 124), не считается ни пройденным тестом, ни подтверждённым дефектом KOMA. Запущенные нами эмуляторы остановлены. Журнал: `verification/device-attempt.log`.

# KOMA 1.1.0

Нативная офлайн-читалка PDF/CBZ для Android 8.0+. Русский интерфейс, графитовая палитра и знак «КАДР». Библиотека при установке пустая. Нет регистрации, сервера или доступа ко всему накопителю.

## Что исправлено в 1.1

- Длинные картинки в CBZ автоматически читаются **по ширине с вертикальной прокруткой**, а не уменьшаются целиком до высоты экрана. Видимые участки декодируются отдельно; позиция внутри страницы сохраняется. Обычные страницы и PDF сохраняют прежний режим. Автоматику можно отключить параметром «Длинные CBZ по ширине».
- Новая манга **не копируется целиком в приложение**. KOMA получает постоянное разрешение Android и читает исходный PDF/ZIP через дескриптор. Сохраняются обложки, база и небольшой кэш.
- Добавлен переход для копий версии 1.0, без потери названий, порядка, прогресса, заметок и настроек.

## Обновление и освобождение места

Установите APK **поверх** существующего приложения. Не удаляйте KOMA и не очищайте её данные: это уничтожит локальную библиотеку. Application ID и сертификат debug-подписи сохранены; миграция Room 1 → 2 проверена отдельным тестом.

Ранее скопированные гигабайты не исчезнут просто от установки обновления: сначала нужно подтвердить доступ к оригиналам.

1. Откройте **Настройки → Память → Убрать копии: выбрать исходники**.
2. Выберите те же PDF/CBZ в системном окне Android. Проверка читает байты для SHA-256, но не создаёт ещё одну копию.
3. В подтверждении появится «Переход без копии: прогресс и закладки сохранятся». Нажмите «Добавить … том(а)».
4. Только после успешной проверки и записи ссылки KOMA удалит свою прежнюю копию. Оригинал останется на месте.

Неподходящий или недоступный исходник не удаляет старую копию. Изменённые байты считаются другим файлом, одинаковое имя не является достаточным совпадением. Уже открываемый внешний файл определяется как дубль.

## Условия чтения без копирования

Исходники должны оставаться доступными. Выбирайте локальные файлы в памяти телефона/на карте памяти для офлайн-чтения. Перемещение, удаление, изменение файла или отзыв доступа могут потребовать повторного выбора; прогресс и закладки при этом сохраняются. Файл из облака не становится офлайн-книгой лишь от добавления ссылки.

SAF-провайдер должен поддерживать постоянное разрешение и произвольный доступ к файлу. Если он отдаёт только поток/временную ссылку, нужно выбрать локальный файл через «+». Автоматический обход с записью гигабайтовой копии не используется. Входящий «Открыть в KOMA» работает, если поставщик даёт сохраняемый доступ; иначе приложение предлагает повторный выбор через системное окно.

Проверка дублей читает файл целиком потоково один раз. Это может занять время для 2 ГБ, но не требует дополнительных 2 ГБ накопителя. Манга в новую приватную папку или cacheDir не записывается.

## Библиотека и чтение

«+» открывает выбор нескольких PDF/CBZ. Перед подтверждением можно исправить название произведения/тома и группировку. Произведения объединяют тома, поддерживают переименование, статус, ручной порядок и перенос. Поиск учитывает название и имя файла без регистра, включая кириллицу. Есть фильтры формата/статуса и сохраняемые сортировка/сетка/список.

RTL: следующая страница — левая зона/свайп вправо. LTR: правая зона/свайп влево. Центр показывает панели. Для длинных страниц — прокрутка по ширине; вертикальный режим объединяет страницы в ленту. Доступны двойное касание, pinch/pan, миниатюры, перемотка с отдельным предпросмотром, закладки и заметки. Позиция внутри длинной страницы восстанавливается после Activity recreation. На последней странице завершение тома и переход к следующему предлагаются явно.

Яркость, удержание экрана и управление громкостью действуют только в читалке. Индивидуальные nullable-переопределения наследуют общие настройки; «Как по умолчанию» снимает их. Направление не зеркалит рисунок, тёмная тема не инвертирует страницы.

CBZ читает JPEG/PNG/WebP. Полные пути сортируются естественно: 1, 2, 10, с учётом папок. Регистр сравнивается без учёта различий, окончательное равенство разрешается по исходному пути (`A` до `a`, `01` до `1`). Каталоги, скрытые записи, `__MACOSX`, `..` и неподдерживаемые файлы пропускаются. ZIP/ZIP64 индексируется через FileChannel без распаковки; длинные смещения проверены тестом за границей 4 ГиБ.

## Память и резервная копия

В «Памяти» показаны оставшиеся локальные копии старой версии и отдельный кэш. Очистка кэша не удаляет мангу, прогресс или заметки. Удаление тома убирает запись и связанные данные, а также его старую приватную копию, если она есть. **Исходный пользовательский документ не удаляется.** История очищается независимо от прогресса и закладок.

Резервная копия JSON содержит метаданные, позиции, закладки, заметки и настройки, **без файлов манги и без ссылок доступа текущего устройства**. При восстановлении недостающие файлы добавляются повторным выбором и сопоставляются по SHA-256. Слияние сохраняет локальные совпадающие записи; неподдерживаемый/повреждённый JSON отклоняется до записи. Подробности: [BACKUP_FORMAT.md](docs/BACKUP_FORMAT.md).

## Сборка и установка

Нужны полный JDK 17/21, Android SDK Platform 35 / Build Tools 35.0.0 и доступ к Google Maven/Maven Central/Gradle. Укажите ANDROID_HOME либо свой игнорируемый local.properties с sdk.dir. Закреплены Gradle 8.11.1, AGP 8.9.2, Kotlin 2.1.20; зависимости не используют динамические версии.

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
./gradlew :app:assembleDebugAndroidTest
./gradlew :app:connectedDebugAndroidTest # только на стабильном устройстве/эмуляторе
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n dev.koma.reader/.MainActivity
```

Готовый APK: `downloads/KOMA-debug.apk`, SHA-256 рядом. Исходники без кэшей/toolchain: `downloads/KOMA-source.zip`. Application ID: `dev.koma.reader`; версия 1.1.0, versionCode 2. Это debug-сборка, ключ публикации не настроен.

Проверки и ограничения: [VERIFICATION.md](docs/VERIFICATION.md). Статус: [IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md). Снимки настоящего Compose-интерфейса: [SCREENSHOTS.md](docs/SCREENSHOTS.md). Архитектура: [ARCHITECTURE.md](docs/ARCHITECTURE.md).

`python3 tools/generate_fixtures.py` создаёт собственные PDF/CBZ, включая длинную страницу 600 × 24000. Это тестовые документы, не встроенная библиотека. Тесты используют Robolectric 4.17 с настоящим native BitmapRegionDecoder для проверки пикселей.

Универсальный ввод паролей PDF, подключение папки, развороты, обрезка полей и полный экспорт книг — [ROADMAP.md](docs/ROADMAP.md). Плитки длинной страницы ограничены бюджетом памяти, это не неограниченный зум. Реальный пользовательский CBZ из отчёта не был приложен; исправление воспроизведено на длинном тестовом CBZ.

# Folio для Android

Приложение для чтения PDF и CBZ на Android 8.0 и новее. Устанавливается как APK, интерфейс и движок чтения встроены в приложение. Сервер и регистрация не нужны. Основа: Capacitor 7 и локальная читалка PDF.js / fflate в Android WebView.

## Возможности

- Системный выбор PDF и CBZ с устройства.
- Библиотека в локальном IndexedDB приложения, сохранение страницы.
- Масштаб, тёмная тема чтения, переход к странице, полноэкранный режим.
- Кнопка Android «Назад» возвращает из книги в библиотеку.
- Шрифты включены в APK; загрузка внешних шрифтов не нужна.
- Доступ ко всем файлам устройства не запрашивается: только к выбранным пользователем.

CBZ — ZIP с JPEG, PNG, WebP, GIF, AVIF или BMP, страницы сортируются по именам с учётом чисел. Поддержка отдельных форматов изображений зависит от Android System WebView. Обновите Android System WebView перед использованием. Защищённые паролем PDF пока не поддерживаются. Файлы до 200 МБ; распакованный CBZ до 512 МБ. Большие книги требуют свободной памяти. Удаление приложения или очистка его данных удаляет библиотеку.

## Сборка APK

Нужны Node.js 22+, **JDK 21** (не только JRE), Android SDK Platform 35 и Build Tools 35.0.0. Gradle Wrapper включён в репозиторий.

```sh
npm ci
# Установите SDK через Android Studio или скрипт для Linux:
bash scripts/setup-jdk.sh
bash scripts/setup-android-sdk.sh
# Укажите свой SDK и JDK при отличии от облачных путей:
export ANDROID_HOME=/workspace/android-sdk
export JAVA_HOME=/workspace/toolchains/jdk-21.0.13+9
npm run android:apk
```

Результат: `android/app/build/outputs/apk/debug/app-debug.apk`. Это подписанная отладочным ключом сборка для самостоятельной установки, не публикация в Google Play. Передайте APK на телефон, откройте его и разрешите установку для выбранного файлового менеджера. Для обновления с сохранением книг используйте тот же ключ подписи. Ключи не добавляйте в Git.

Для Android Studio: `npm run android:sync`, затем `npm run android:open`. Для публикации потребуется отдельная release-подпись и AAB; здесь они не создаются.

## Проверки

```sh
npm run build
# Браузерные тесты движка чтения:
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test
# Если системного Chromium нет:
npx playwright install chromium
npm test
# Сборка и Android lint:
npm run android:apk
```

Тесты браузера проверяют PDF/CBZ, перелистывание, сохранение позиции, фильтры, удаление, ошибки и мобильную раскладку. Они не заменяют проверку системного выбора файлов и кнопки «Назад» на настоящем Android-устройстве.

Для отладки интерфейса отдельно: `npm run dev`.

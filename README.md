# KOMA

Нативная офлайн-читалка локальной манги PDF/CBZ для Android 8.0+ (minSdk 26). Русский интерфейс, графитовая палитра и утверждённый знак «КАДР». Библиотека при установке пустая. Сети, регистрации и общего доступа к накопителю приложение не требует.

## Сборка

Нужны полный JDK 17 или 21 (с `javac`), Android SDK Platform 35, Build Tools 35.0.0 и доступ к Google Maven/Maven Central/Gradle. Версии закреплены: AGP 8.9.2, Gradle 8.11.1, Kotlin 2.1.20; остальные зависимости — в app/build.gradle.kts. Gradle Wrapper проверяет SHA-256 дистрибутива.

Откройте корень проекта в Android Studio либо задайте `ANDROID_HOME` (или создайте свой игнорируемый `local.properties` с `sdk.dir`):

```sh
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest :app:lintDebug
./gradlew :app:connectedDebugAndroidTest # только с устройством/эмулятором
```

Debug APK: `app/build/outputs/apk/debug/app-debug.apk`. Установка:

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n dev.koma.reader/.MainActivity
```

Application ID: `dev.koma.reader`. Для смены измените applicationId; namespace и Kotlin-пакеты можно оставить. Подпись для публикации не настроена; debug-подпись подходит для тестирования, не для релиза.

## Импорт и библиотека

Нажмите «+» или «Выбрать файлы». Выберите несколько PDF/CBZ через системное окно. KOMA сначала копирует файлы во временное приватное хранилище, проверяет содержимое и SHA-256, затем показывает список для подтверждения. Исправьте название произведения/тома или выберите существующее произведение; нажмите «Добавить … том(а)». Дубликат определяется байтами, а не именем. Для большого файла показывается фактически скопированный объём. При отмене незавершённые временные копии удаляются; уже подтверждённые тома остаются. После завершения процесса незавершённый импорт нужно начать снова.

PDF/CBZ сохраняются в постоянном приватном хранилище, оригиналы остаются на месте. Доступно «Открыть в KOMA» из других приложений. Некоторые поставщики помечают CBZ как ZIP или общий бинарный файл; реальный формат всё равно проверяется.

Поиск учитывает название произведения и исходное имя файла без учёта регистра, включая кириллицу. Фильтры статуса и формата работают совместно. Смешанное произведение соответствует формату, если содержит хотя бы один такой том. Вид, сортировка и фильтры сохраняются.

Том открывается из произведения. Меню тома позволяет переименовать, переставить, перенести или удалить его с подтверждением. Статус произведения отделён от позиции: перемотка не отмечает мангу прочитанной. Удаление последнего тома убирает пустое произведение. Перенос последнего тома также убирает старую пустую карточку.

## Чтение

В режиме справа налево левая зона и свайп вправо открывают следующую страницу; справа/свайп влево — предыдущую. В режиме слева направо — наоборот. Центр показывает панели. В ленте работают вертикальная прокрутка и сохранение относительного положения в странице. Двойное касание и pinch увеличивают страницу, при увеличении панорамирование не перелистывает её. Направление не зеркалит рисунок.

Перемотка показывает предварительный номер/миниатюру и сохраняет позицию только после отпускания. «Страницы» открывает миниатюры. Закладка сохраняет точную страницу; заметки редактируются во вкладке «Закладки». Удалённую закладку можно вернуть через snackbar. На последней странице завершение тома и переход к следующему предлагаются явно.

Настройки читалки сохраняются для произведения. Неизменённые параметры наследуют общие настройки. «Как по умолчанию» снимает все переопределения. Яркость, удержание экрана и перехват громкости относятся только к читалке. Изображения сохраняют исходные цвета.

CBZ сортируется естественно по **полному пути** (папки тоже участвуют): `1`, `2`, `10`. Сравнение текстовых токенов игнорирует регистр; окончательное разрешение равенства — по исходной строке, поэтому `A.png` перед `a.png`, `01.png` перед `1.png`. Подкаталоги не сливаются. Скрытые/служебные файлы, `__MACOSX`, `..`, каталоги и неизвестные форматы пропускаются. Архив не распаковывается на накопитель.

## Память и резервная копия

Кэш содержит только пересоздаваемые миниатюры/страницы. Его очистка сохраняет мангу, базу, позиции и заметки. История очищается отдельно и также не меняет прогресс.

«Настройки → Резервная копия» экспортирует JSON через системное окно. **Файлы манги в копию не входят.** Восстановление объединяет записи: локальные совпадения по ID/SHA-256 и заметки по том/страница имеют приоритет; настройки восстанавливаются в пустую библиотеку. Отсутствующие книги показывают «Добавьте файл». Повторно импортируйте те же байты PDF/CBZ: позиции и закладки привяжутся автоматически. Ошибочный или неподдерживаемый JSON отклоняется до изменения базы. Правила и схема: [BACKUP_FORMAT.md](docs/BACKUP_FORMAT.md).

## Проверки и ограничения

Фактические команды, результаты, скриншоты и непроверенные сценарии: [VERIFICATION.md](docs/VERIFICATION.md). Статус реализации: [IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md). Задание сохранено в [PRODUCT_REQUIREMENTS.md](docs/PRODUCT_REQUIREMENTS.md); визуальные ориентиры — `references/`, исходники знака — `design/`.

Тестовые документы создаются `python3 tools/generate_fixtures.py`, находятся в `test-documents/` и не включаются в пользовательскую библиотеку. Unit-тесты проверяют natural sort, наследование, базу, позиции, дубли, восстановление и удаление связанных записей. Инструментальный тест предназначен для Android-устройства.

Защищённые паролем PDF не открываются: требуется незашифрованный файл. Оглавление не выдумывается; доступны страницы и тома. Импорт не является гарантированной фоновой службой. Масштабирование имеет предел разрешения и памяти, не является тайловым движком для бесконечного зума. Расширения после первой версии перечислены в [ROADMAP.md](docs/ROADMAP.md).
